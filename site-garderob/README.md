# Garderob Store — демо-сайт

Женская одежда, обувь и аксессуары. Казань и Набережные Челны.
Версия 2: с реальными фото, ценами и размерами из их Telegram-канала.

- Канал: https://t.me/garderob_store_chelny (12,1 тыс. подписчиков)
- Менеджер: @garderobstore_chelnyy
- Их текущий сайт: https://club210891062.orgs.biz/ (конструктор orgs.biz)
- Карточка 2ГИС (Челны): https://2gis.ru/nabchelny/geo/70000001084250399

## Сборка

```
python3 inject.py      # photos/*.jpg + index.src.html → index.html (версия для артефакта)
python3 build.py       # index.html → dist/ (готовый сайт с <head>, мета, Schema.org)
```

`garderob-store-site.zip` — архив папки `dist/`, то, что отдаётся клиенту:
index.html со вшитыми фото, robots.txt, sitemap.xml, favicon.svg, og.jpg
и КАК-ЗАПУСТИТЬ.txt с пошаговой инструкцией для того, кто будет
выкладывать сайт. Домен в файлах — заглушка `garderob-store.ru`,
меняется поиском-заменой (шаг 2 инструкции) или в начале `build.py`.

`index.src.html` — исходник с метками `{{PHOTO:имя}}`, `photos/` — сжатые
фотографии, `index.html` — собранный файл для публикации. Фото вшиваются
как data:URI: прямые ссылки на картинки Telegram с чужого домена не
загрузятся ни в артефакте, ни на обычном хостинге.

## Проверить у клиента перед запуском

1. **Джемпер с принтом** — цена не указана: подпись «Кардиган на молнии
   3190 ₽» шла следующим постом после этого альбома, но на фото явно не
   кардиган на молнии, поэтому цену к нему не привязывали. Спросить
   у клиента и проставить.
2. **Число залов.** На их сайте — 6 адресов в Казани и один в Челнах,
   в 2ГИС в Челнах три. Уточнить актуальный список.
3. **Отзывы** — взять из 2ГИС.
4. **Фото** — у нас только превью из веб-версии канала (450–600 px по
   ширине). Для продакшена нужны оригиналы: у них 45 тысяч фотографий,
   качество будет заметно выше.
